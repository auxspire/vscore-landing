Let’s introduce a visual design improvement to the main bottom navigation tab in the VScor app to make it feel more modern and visually appealing.

Current Design

The current bottom tab bar is a plain rectangular strip.

It touches the left and right edges of the screen.

The scoring tab in the center looks similar to the other tabs.

Required Design Changes
1️⃣ Floating Tab Bar

Redesign the bottom navigation bar so that:

The tab bar does not touch the screen edges.

It appears slightly floating above the bottom of the screen.

Maintain horizontal margins on both sides.

Add rounded corners on both ends.

Design characteristics:

Floating card-like appearance

Soft shadow below the tab bar

Smooth rounded edges

2️⃣ Center Scoring Button Highlight

The central scoring tab should have stronger visual emphasis because it is the most important action in the app.

Design changes:

Place the scoring button inside a circular button

The circle should have a slightly larger diameter than the height of the tab bar

The circle may slightly protrude above the tab bar

Visual suggestions:

Elevated floating button style

Slight shadow for depth

Clear icon indicating scoring or match action

3️⃣ Visual Hierarchy

The design should communicate:

Center button → primary action (scoring)

Side tabs → secondary navigation

4️⃣ Design Goals

The updated navigation should feel:

Modern

Lightweight

Easy to tap

Visually balanced

Suitable for frequent match scoring usage

5️⃣ Inspiration

Design style can follow patterns similar to:

Floating navigation bars in modern mobile apps

Floating action buttons used in sports or productivity apps

But maintain simplicity and speed, since VScor is used during live matches.

Expected Result

A floating bottom navigation bar

Rounded edges

Central circular scoring button

Better visual hierarchy and usability for the scoring action

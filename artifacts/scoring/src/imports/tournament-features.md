1️⃣ Display Organizer Information

In the Tournament Profile Page, clearly display the Organizer Information.

The section should show:

Organizer Name

Organizer Contact Number (or primary contact detail)

This information should be visible to all users who view the tournament profile.

Purpose:

Helps teams or players contact the tournament organizer easily.

2️⃣ Edit Permission Control

The Edit option for tournament details should only be visible to users with editing authority.

Users allowed to edit:

Tournament Owner

The user who created the tournament

Or the user who received ownership through ownership transfer

Tournament Coordinators

Users without permission should:

Be able to view tournament details

Not see the Edit button

3️⃣ Coordinator Management

When adding coordinators in the following places:

Create Tournament Screen

Edit Tournament Details Dialog

The coordinator input field should behave as a user search selector.

Coordinator Selection Behavior

When the user starts typing a name:

The system should suggest existing users from the app.

Suggestions should show:

User name

Profile photo (if available)

Contact number (optional preview)

Auto-fill Contact Information

When a user is selected as a Coordinator:

The contact number field should automatically populate based on that user's profile data.

This avoids manual entry errors and ensures correct contact information.

4️⃣ Coordinator Rules

A tournament can have up to 3 coordinators.

One of them must be the tournament creator (owner).

Coordinators can:

Edit tournament details

Manage teams

Manage fixtures

5️⃣ Validation Rules

Ensure the system enforces:

No duplicate coordinators

Only registered users can be coordinators

Maximum coordinator limit is respected

Expected Outcome

After implementation:

Tournament organizer information is clearly visible.

Editing controls are restricted to authorized users.

Coordinator selection is faster and less error-prone.

Contact details remain accurate and consistent.
